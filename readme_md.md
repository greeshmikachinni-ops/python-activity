# Feel It — Music Streaming Website

**Live Demo:** [https://greeshmikachinni-ops.github.io/feel-it-/](https://greeshmikachinni-ops.github.io/feel-it-/)

**Feel It** is a responsive, modern music streaming web application built using HTML5 and CSS3 (with interactive JavaScript playback). It features a clean dark-themed interface, organized media grids, and a persistent bottom music player.

---

## Key Features

- **Navigation & Search:** Responsive sidebar navigation with quick jump links to sections and a live search bar to filter tracks in real time.
- **Featured Hero Banner:** Eye-catching showcase banner with quick-play and library-save buttons.
- **Recently Played:** Compact cards displaying recently streamed tracks for instant replay.
- **Popular Tracks:** Numbered tracklist showing song artwork, artist name, album title, duration, and active track highlighting.
- **Featured Artists:** Circular artist cards displaying artist profiles and monthly listener stats.
- **Top Albums & Curated Playlists:** Responsive grid layouts with hover play triggers and mood-based collections.
- **Persistent Music Player:** Sticky bottom audio bar featuring track info, like/favorite button, play/pause, previous/next controls, interactive progress scrubber, and volume slider.

---

## Technologies Used

- **HTML5:** Semantic structure (`<aside>`, `<main>`, `<header>`, `<section>`, `<article>`, `<footer>`) and accessible attributes.
- **CSS3:** Custom CSS variables, CSS Grid, Flexbox, responsive media queries, glassmorphism (`backdrop-filter`), and smooth hover transitions.
- **JavaScript:** Dynamic track switching, playback controls, search filtering, and progress bar interaction.

## How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/greeshmikachinni-ops/feel-it-.git
   ```
2. **Navigate into the folder:**
   ```bash
   cd feel-it-
   ```
3. **Launch the webpage:**
   Open `index.html` directly in any web browser or run it via VS Code Live Server.
